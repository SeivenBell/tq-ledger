# tq-ledger — Build North research and build handoff

**Planning repository; the Q-Day Ledger application is not built or deployed.** The conditional recommendation is a source-linked quantum-resource claim comparison/refusal workbench. The final project choice remains [open](https://github.com/SeivenBell/tq-ledger/issues/14).

Start with the [briefing](docs/BRIEFING-2026-10-24.md): recommendation, scientific background, competition, account status and next actions. It is dated for the Oct24–25,2026 build window; recheck event deadlines and account balances before acting later.

- [Decision memo](docs/decision/ranked-memo.md): alternatives, evidence and reasons the recommendation could fail.
- [Product](docs/build/PRODUCT.md), [architecture](docs/build/ARCHITECTURE.md), [build plan](docs/build/PLAN.md): implementation contract, not achieved functionality.
- [Demo plan](docs/build/DEMO.md), [Devpost preparation](docs/build/DEVPOST.md), [outreach drafts](docs/build/OUTREACH.md): unsent/unpublished preparation.
- [Practitioner findings](docs/research/practitioner-pain.md), [fact-check](docs/research/build/demo-fact-check.md), [red-team](docs/research/build/plan-red-team.md): source depths and limits.
- [QRef backup probe](prototypes/qref-probe/README.md): runnable small-circuit feasibility demonstration; 11 expected verdicts matched, including five deliberately planted failures. Not a real-world agent-error rate.
- [Integration evidence](docs/research/build/integration-checks.md): what was actually exercised and what remains unverified.

Repository code is Apache-2.0; cited papers, platform records and other source material retain their own licences/terms. Research quotation candidates are not independently certified scientific claims.
