## What to understand for a practitioner call

For the upgrade-review direction:

- Circuit equivalence does not prove the surrounding Python program or experiment is unchanged.
- A shot is one measurement. Changing the number of shots changes sampling uncertainty even if the circuit matches.
- An old reference program can contain a bug. Preserving history and correcting intent are different review decisions.
- Small noiseless simulation does not validate hardware behavior, noise or every input.

A useful opening question is: “Can you show me the last notebook upgrade you had to review?” Let the actual artifact determine the follow-up. Avoid asking for generic enthusiasm about an AI platform.
